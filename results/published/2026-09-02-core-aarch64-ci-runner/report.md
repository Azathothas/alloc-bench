## Configurations that could not exist

 These are results. Each names a concrete technical reason, and a future upstream release that removes the reason turns the row into a measurement without anyone editing prose.

| cell | reason |
| --- | --- |
| `alpine-aarch64-mesh-rust-global-static-lto-distro` | Mesh exports no prefixed C allocation API. Its published interface is the malloc/free override itself, so there is no symbol for a #[global_allocator] shim to call that is distinguishable from libc's. Verified against the pinned commit: no mesh_malloc / mz_malloc equivalent exists in its headers. |
| `alpine-aarch64-tcmalloc-rust-global-static-lto-distro` | tcmalloc exports no prefixed C allocation API. Its supported interface is the operator-new/malloc replacement plus tcmalloc::MallocExtension (C++), so there is no C symbol for a #[global_allocator] shim to bind to. |
