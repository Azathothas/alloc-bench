=== what that means ===
   A AND C DISAGREE, so this host does not reproduce its own
     ordering and B tells us nothing about core count. That is
     itself the finding: docs/AGENTS.md item 11 recorded the
     same host wandering, and this is a second instance under a
     design built to detect it.
      The experiment is not invalid --- its CONTROL fired, which
       is what a control is for. And the MAGNITUDE table above may
       still separate cleanly even when the ORDER does not: the
       candidates sit within a few percent of each other, so the
       wander swamps the gaps BETWEEN them while leaving each
       one's distance from the control readable.

=== what this probe cannot tell you ===
- whether core count explains it on any OTHER host. One machine.
- whether 2 of 4 pinned cores behaves like a 2-core machine. Cache,
  memory bandwidth and the scheduler's view all differ, which is why
  T-025's option (3) stays open.
- anything about SMT: this host reports 1 thread per core, so the
  hypothesis's OTHER half cannot be varied here at all.
