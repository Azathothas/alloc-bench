=== what this establishes ===
 mesh builds a shared library and always did. The refusal was the
   recipe searching the CMake BINARY directory for an artefact mesh's
   own CMakeLists redirects into the SOURCE directory.
 It is the third refusal in this project that turned out to be the
   instrument rather than the allocator -- after tcmalloc's `find`
   not following the bazel-bin symlink, and its TLS failure being
   reported as "bazel build failed". A refusal is a measurement and
   has to be able to fail for the right reason.

=== what this probe cannot tell you ===
- whether a mesh cell now measures. The ripgrep build, the identity
  gate, preload-check's residency read and the correctness gate all
  sit downstream. Only a run of the `preload` suite answers that.
- whether writing into the source tree is safe for a CACHED source
  directory. allocators/mesh/build.sh now cleans $SRC/build before
  configuring for exactly that reason; this probe uses a fresh clone.
