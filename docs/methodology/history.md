# History

`docs/history/` contains completed work records, reviews, retired plans, and
withdrawn claims. It preserves context but does not define current behavior.

Use the live guide that owns a subject for instructions. When a correction
needs an audit trail, update the live guide and add a dated note under history
that links to the evidence. Never require a reader to reconstruct the current
rule from a sequence of corrections.

The migration retained all completed work records under
`docs/history/todo/`. The original reference corpus was removed after verifying
that build, test, benchmark, and reporting paths did not read it.
