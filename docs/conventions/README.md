# Conventions

These rules apply to current project files. Historical records under
`docs/history/` keep their original wording unless a correction is required.

- [`prose.md`](prose.md): writing
- [`docs.md`](docs.md): documentation structure
- [`code.md`](code.md): implementation
- [`shell.md`](shell.md): shell scripts
- [`git.md`](git.md): commits and remote operations
- [`forbidden-patterns.md`](forbidden-patterns.md): patterns rejected in review
